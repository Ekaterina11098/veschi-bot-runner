# Восстановление дневного отчёта Китая — 17.10.2026

По запросу владельца проверена доставка отчёта кандидатов повышения на 15:00 МСК. В business_agent_jobs и coverage_report отсутствовала запись дневного запуска за 17.10. Причина: china-price-intraday.yml имел только on.push для ручного dated-request; файл оставался armed, report_date=2026-10-16. Cron и workflow_dispatch отсутствовали.

Добавлен ежедневный график 12:00 UTC (15:00 МСК) с ограниченными техническими повторами в 12:15/12:30/12:45 UTC. Сохранён суточный update_id, проверка owner/chat, запись и курсор отправки; выполненное задание повторно не отправляется. Запуск по расписанию рассчитывает дату по Москве и не зависит от устаревшей даты ручного request. Ручной push по-прежнему требует точную дату и source pin. Workflow dispatch поддерживает run и verify, по умолчанию verify.

Проверены 4 сценария валидатора: stale push отклоняется; scheduled запуск со старым request разрешён; ручной verify разрешён; актуальный push run разрешён. YAML успешно разобран. Формулы, отбор кандидатов и source pin не изменялись; действующая миграция чата сохранена.

По явному запросу владельца создан запоздавший запуск за 17.10.2026 с фактическим текущим временем среза; он не объявляется состоявшимся в 15:00. Изменений WB этот процесс не выполняет.
