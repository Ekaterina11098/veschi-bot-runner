# China change observations

The observer registers every verified price, bid, SKU exclusion and new-campaign receipt. Advice never becomes execution authority.

## Windows and history

Use Moscow dates from verified application receipts, exclude the change day and today, and compare equal complete periods. Price decisions use four full days; earlier three-day dates are retained as intermediate historical windows. Specific agreed advertising windows remain unchanged. Every revision, positive/negative preliminary result, concurrent change and missing input is preserved. An incomplete refresh does not erase prior evidence. Observations continue after a first positive day.

Current WB parameters must still match the experiment before considering a rollback. Bid rollback additionally requires fresh minimum/step verification. Small samples, incomplete costs or concurrent changes prevent an unsupported rollback recommendation. Proposals contain no execution jobs; human confirmation of a concrete plan remains mandatory.

## Measurements and money

WB orders have priority. Reconcile separate MPStats counters and order rows; never deduplicate multiple real units by gnumber. Only srid authorizes unit deduplication. Completed kept buyouts, refusals/cancellations, returns, pending and unknown outcomes remain separate.

Compare WB orders, all-source card openings / click-to-order, completed cohort buyout, actual reconciled DRR, advertising-only impressions/clicks/CTR/CPC and total expected profit. Period advertising is deducted once and not multiplied by buyout. Current COGS, historical logistics, fee/tax scenarios, cancellation reserves and unclassified charges are explicit limitations. Profit/order is not a ranking criterion.

Full closed-cohort actual profit requires reconciled source IDs, unique expense IDs, confirmed tax/COGS/logistics/shared charges and advertising reconciliation. Published Finance-derived operation-date contributions are read separately; they are not closed order-cohort profit and cannot silently determine a price-test outcome. Missing financial totals remain null.

General impressions and organic impressions are never replaced by advertising views. Prefer a verified total that already includes advertising. Add organic and paid components, or derive organic by subtraction, only when identical periods/units and non-overlap are verified. Available all-source WB UI metrics are distinct from the current MCP/API transport; absent API fields remain a documented collection gap.

## Runtime

Collection is attached to the existing morning advertising run and backups, with caching and a bounded read budget. No new polling schedule, marketplace writes or direct observer Telegram sends. Due compact results join the existing daily attention report. Non-informative waiting blocks are hidden until evaluation. Full outcome PNGs are available on explicit request.

All operational data, images, receipts and audits stay private. Only the public runner executes. Existing source pins, confirmation handlers, price-report schedules and dedicated campaign monitors remain unchanged.
