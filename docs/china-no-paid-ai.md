# China bot: no paid model API

Owner requested no additional model API charges. Cloud dialogue and analysis policies are disabled privately. Paid SDK construction and legacy metered requests fail before network access. Active China workflows no longer receive an OpenAI key.

The existing scoped Telegram bridge handles deterministic conversion, catalogue price, growth-candidate and report requests. Existing sender/chat checks, job claims, frozen reports and delivery receipts remain in force. Unknown inputs return supported commands; they do not silently fall back to a model. This is a limited command interface, not free unrestricted AI.

Existing data collection, source pins, report schedules and explicitly bound execution permissions are unchanged. No model/provider, paid service or new subscription is activated. Past consumption and other applications sharing the account are outside this code's billing control. ChatGPT subscription and usage limits are controlled by OpenAI, not by the Telegram bot.
